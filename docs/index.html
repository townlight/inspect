Inspection drafts that keep inspectors in charge.

Townlight Inspections v0.2.2 inspection support + staff review queues is a narrow truth-repair release with no functional upgrade. It exists solely to supersede the false v1.0.0 release from 2026-05-21 in GitHub's Latest impression; the Townlight Core pin is unchanged.

v0.2.2 corrective demotion state

What is available

  • Repeat-case lookup.
  • Inspector-owned report draft helper.
  • Notice draft helper with staff actions.
  • Staff-only review queues.
  • Records-ready export checklist.
  • Public sample UI at /civicinspect.

What is not available

Townlight Inspections does not issue official findings, citations, fines, notices, inspection scheduling, legal advice, live photo analysis, live LLM calls, or system-of-record integrations.

Integration boundary

Review packets can carry Townlight Code and inspection case context IDs. Adversarial local mocks reject spoofed roles, attempted enforcement actions, stale context, and live photo-analysis claims.
