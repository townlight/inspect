# Townlight Inspections Implementation Plan

Townlight Inspections v0.2.1 ships the inspection support product lane: runtime shell, repeat-case lookup, staff-gated case/report persistence, staff review queue workflows, review-required CivicCode/case context packets, adversarial local integration mocks, inspector-owned report drafts, notice draft helpers, records-ready export checklist, public sample UI, and Townlight Core v1.1 alignment.

Later releases may add live media workflows, production identity integration, scheduling-system connectors, and deeper case-system integrations. Those are not required for this v1.0.0 local product lane.
